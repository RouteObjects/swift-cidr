# swift-cidr 0.6.0

## Summary

`swift-cidr` 0.6.0 adds fixed-size, network-byte-order octet adapters to
`IPv4Address` and `IPv6Address`. Integer storage remains the canonical
representation for identity and CIDR math.

## Highlights

- Adds `init(octets:prefixLength:)` and `octets` to `IPv4Address` using
  `InlineArray<4, UInt8>`.
- Adds the corresponding IPv6 APIs using `InlineArray<16, UInt8>`.
- Defaults omitted prefix context to `/32` for IPv4 and `/128` for IPv6, matching
  the existing integer initializers.
- Preserves every address bit, including host bits; the adapters neither mask to
  a network boundary nor attach IPv6 scope.
- Keeps `UInt32` and `UInt128` as stored address representations. Equality,
  hashing, ordering, parsing, formatting, and Codable behavior are unchanged.
- Provides an exact, allocation-free, text-free interoperability boundary for
  packet, protocol, and FFI code without making octets the primary math model.

## Compatibility and Downstream Migration

This release raises the package's minimum Swift tools version from 6.1 to 6.2,
the first toolchain version that provides `InlineArray`. The existing minimum
deployment targets remain macOS 15 and iOS 18 because all pre-0.6 APIs retain
their availability.

The new octet APIs require macOS 26, iOS 26, tvOS 26, watchOS 26, or visionOS
26 on Apple platforms. They are available on Linux with Swift 6.2 or later.
Callers supporting earlier Apple versions can continue using the existing
integer, text, POSIX, and SwiftNIO boundaries.

Downstream packages that are not ready to adopt the Swift 6.2 package floor
should remain on `swift-cidr` 0.5.x. In particular, `cidrwalk` 0.2.0 constrains
its dependency to `swift-cidr >=0.5.0,<0.6.0` before this release is tagged.

No adapter is added to `IPNetwork`, `AnyIPAddress`, MAC-family types,
`CIDRPOSIX`, or `CIDRNIO`. The returned `InlineArray` is an owned projection,
not a borrowed view.

## Validation Before Tagging

- Run `./scripts/test.sh` with Swift 6.2 and Swift 6.3.
- Build the `CIDR`, `CIDRPOSIX`, and `CIDRNIO` products.
- Build for the retained macOS 15 and iOS 18 deployment targets, and exercise
  the octet adapters on Apple OS 26.
- Run `./scripts/benchmarks.sh build`, the guarded octet-adapter measurements,
  and `./scripts/benchmarks.sh check`.
- Run Linux tests and benchmark-target compilation.
- Extract and audit the public symbol graph and convert DocC with warnings
  treated as errors.
- Confirm `cidrwalk` 0.2.0 and its Homebrew formula are public and resolve
  `swift-cidr` below 0.6.0.
- Create the SSH-signed annotated `0.6.0` tag only after the feature branch has
  been reviewed and merged.
