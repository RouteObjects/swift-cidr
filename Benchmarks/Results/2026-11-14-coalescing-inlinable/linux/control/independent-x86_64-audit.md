# Independent x86-64 Linux audit

Passed. All 132 measured samples (192 processes), 22 excluded warmup samples (32 processes), and 224 retained stdout/rusage files were independently checked. Every output hash matches its original independently verified coverage reference. Raw per-child RSS conversion, elapsed/CPU sums, split RSS maxima, controlled environments, commands, sequential chronology, progress order and sample inventories pass. Six pairs per workload include three B/C and three C/B orders. All 22 group statistics and 66 paired comparisons match independent recomputation. No samples were removed or retried.

The audit checked 667 hashes and 5,128 assertions, including frozen binaries/sources/helpers, original coverage references, codegen evidence and actual binary bindings, locked dependency pins, and all ten build/test receipts. Eight test configurations account for 1,414 passing test executions. Final controller completion and runtime postcheck receipts pass; no validation-failed receipt exists.

Two audit-reader attempts were retained separately. `independent-x86_64-audit-logdecode-v1.json` records strict UTF-8 decoding failure where a native-build warning interleaved within the bytes of a test-status checkmark; the frozen log hash and final ASCII test result are intact. The reader now extracts the ASCII result with a bytes regex and records the encoding anomaly. `independent-x86_64-audit-schema-v2.json` records an assumed `at` field absent from the x86 codegen gate. The final audit uses the actual gate schema: its hash is bound by the pre-benchmark freeze and the start validation receipt. These were audit-reader failures, not failed tests or benchmark processes. The byte-parser adjustment was checked against all eight ARM64 test logs; a full ARM64 hash rerun was unnecessary.

All unusual timing observations remain included. See [x86_64-outlier-review.md](x86_64-outlier-review.md) and its JSON for wall/CPU/counter comparisons and exact raw-record hashes. Do not generalize small median changes beyond this six-pair sample.

The audit launches no benchmark, test, build, coverage or disassembly process. Native runtime library bytes are not rehashed from this Mac retrieval host; the frozen runtime record and matching postcheck receipt are verified. Raw nanosecond values are checked for accounting consistency rather than independently remeasured. Codegen gate/evidence hashes are checked without repeating disassembly interpretation.
